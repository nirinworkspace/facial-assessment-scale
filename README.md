# Facial Assessment Scale

Interactive clinical evaluation tool and standardized severity chart.

## Features
- **Interactive Radial Scale**: Visual scoring across 16 facial parameters across 4 domains (Skin Quality, Facial Shape, Dynamic Lines, Static Lines).
- **Comprehensive Assessment Table**: Parameter-by-parameter clinical scoring with notes.
- **Baseline Comparison**: Overlay baseline assessments to evaluate treatment outcomes.
- **Export Capabilities**: High-res PNG chart export, PDF/Print report, and JSON data export.

## Deployment
Static front-end web application (HTML, CSS, JavaScript).
Compatible with Cloudflare Pages, GitHub Pages, or any static web hosting.
